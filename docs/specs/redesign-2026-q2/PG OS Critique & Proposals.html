01 // HOMEEMPTY GLANCE

Home is a list, not a glance.

The current Home stacks vitals + drip log + queue + projects vertically, all at the same visual weight. Nothing earns the eye. There's no single sentence that tells me what kind of day it is. Glance = read.

02 // HABITSCHORE FATIGUE

Habits feel like chores, not rituals.

Identical pill rows for "Morning Pages" and "Take vitamins" flatten the meaning. There's no warm-up, no closeout, no ceremony around the ones that actually shape the day. The streak ★ glyph is the only literary hand.

SEVERITY · HIGHFIX · P1.B · MORNING / P1.C · EVENING
03 // PROJECTSFLAT DENSITY

Projects is dense, but flat.

All seven projects look equally alive. Hero's Chronicle (your shipping focus) sits beside Career-Ops (idle) at the same weight. The card chrome is identical; the data is not. There's a hierarchy — the UI doesn't show it.

SEVERITY · MEDFIX · P2.A · FOCUS PIN
04 // CLAUDEDATA DUMP

Claude tab is a firehose.

Seven sub-tabs, dozens of sentences, and zero "so what." Proposals aren't ranked; trust state has no hand-off; signals are bar charts without prose. The most powerful surface in the app reads like a debug screen.

02 // PRINCIPLES · BEFORE THE FIXES

Four rules to steer by.

REUSABLE FOR ANY
FUTURE PG OS PROPOSAL
01 // RULE
One sentence at the top.

Every screen earns a single literary line. "Working late, Patrick." is more useful than four cards of telemetry.

02 // RULE
Show the verb, hide the data.

Surface 1–3 next actions. Bury the rest behind expand. Data is the receipt of the action, not the action.

03 // RULE
Bookends carry weight.

Morning and evening get bespoke surfaces — not cards inside the grid. Treat them like ceremonies.

04 // RULE
Modes mean something.

Day/Twilight/Midnight should change behavior — not just hex codes. Quieter coaching at midnight, livelier at golden hour.

P1.B // BIG SWING · BRIEFINGSHIPPABLE Q2

The Morning Briefing.

A dedicated full-bleed screen that runs once per day, before the dashboard ever appears. Hero painting + one literary sentence + 1–3 narrated actions written by Claude in your voice. No grid, no chrome, no tabs. You read three lines, you press Begin, you arrive.

WHY · Today's "RitualGate above habits" is a checkbox. This is a doorway. It uses your existing hero imagery + literary voice as the front door, then drops you into the OS already oriented. Replaces the 90 seconds you currently spend scanning to "see what's up."
BUILD · /briefing route · gates Home until dismissed once · Claude assembles narration from calendar+queue+projects · auto-shows 06:00–10:00 local · localStorage `pg-os-briefing-YYYYMMDD`.

P1.C // BIG SWING · CEREMONYSHIPPABLE Q2

The Evening Ceremony.

A back door for the day. Auto-fired around 21:00 (or on-demand from ⌘K). Reads back what you actually did — commits, ships, captures, habits — in plain English, in your voice. Asks one optional sentence: "what mattered today?" Files everything to the journal. Closes with a date stamp and a small chime.

WHY · Closes the loop the morning briefing opens. Right now your day ends mid-tab. Sleep + recovery data feeds the next morning's narration — the OS literally remembers. Solves the "log the day" problem without a form.
BUILD · /evening route · auto-summarize from agent_runs + git + ships + queue closures · single textarea write to HC journal · post chime via Web Audio.

P3.B // BIG SWING · NOWSHIPPABLE Q3

Now Mode.

A fullscreen state the OS slips into when you commit to a focus block. Five minutes of typing in Flow → OS quietly dims everything except: the focus title, an elapsed timer, and what's queued next. Hit Esc to come back. The rest of the dashboard is paused, not just hidden — pings, polls, fetches all stand down.

WHY · The operator card already has FOCUS · DEEP WORK. Right now that label coexists with a still-busy UI. Now Mode makes the label real. Pairs cleanly with the timer-driven Flow tab and gives the Spotify card a reason to stay (ambient soundtrack).
BUILD · kbd ⌘. toggles · CSS class on hides everything except .now-stage · pauses SSE channels · respects prefers-reduced-motion.
